# 路书 · Web 版自驾行程规划

一个面向国内自驾游的行程规划（路书）工具：按「天」组织路线，设置每天起点、终点和途经点，自动计算里程 / 驾驶时长 / 过路费，在地图上以不同颜色展示每天的路线，并推算每个地点的到达时间。

当前进度：**M1 原型已完成**，支持**双地图数据源**（开源模式免 Key 可直接测试 / 高德模式为正式模式）。数据存浏览器本地。完整规划见 [docs/PLAN.md](docs/PLAN.md)。

## 快速开始

```bash
npm install
npm run dev        # http://localhost:5173
```

首次打开选择地图数据源：

**🌍 开源地图（免 Key，推荐先用于测试）**——Leaflet + OpenStreetMap 瓦片，路线用 [OSRM 演示服务](https://router.project-osrm.org)，POI 搜索/逆地理用 [Nominatim](https://nominatim.openstreetmap.org)。打开即用，无需注册。注意：国内地点数据较稀疏；OSRM 演示服务仅默认策略、无过路费数据；Nominatim 有每秒 1 次的使用限制，请勿高频压测。

**🇨🇳 高德地图（正式模式）**——数据与搜索质量更好，支持过路费与路线策略：

1. 打开 [console.amap.com/dev/key/app](https://console.amap.com/dev/key/app)，注册并实名认证；
2. 「应用管理 → 创建新应用 → 添加 Key」，服务平台选择 **Web端(JS API)**；
3. 2021-12-02 之后申请的 Key 会同时生成**安全密钥（jscode）**，一并填入；
4. Key 只保存在本机浏览器 localStorage；正式部署时请在高德控制台为该 Key 配置域名白名单。

> ⚠️ 两种地图坐标系不同（开源 WGS-84 / 高德 GCJ-02）。切换数据源会清空路线缓存并重算，同一坐标可能显示偏移数百米，请勿混用。

## 已实现功能（M1）

- **路书列表首页**：多路书管理——列表卡片（标题 / 日期 / 天数 / 总里程 / 更新时间）、创建新路书、删除（带确认）、按最近编辑排序；旧版单路书数据自动迁移
- **多天路书**：创建（名称 / 出发日期 / 天数），天数随时增减，删除有确认
- **逐点添加的日程**：每天就是一个有序地点列表，无固定起点/终点，也没有多余设置项——底部一个「＋ 添加节点」按钮，点开卡片**在卡片内搜索**并选择地点即完成添加；每个节点可随时点 ✏️ 进入自己的编辑卡片（改名 / 重新搜索更换地点）；自动算出与上一地点的行车距离；最后一个地点通常是当晚住宿
- **跨天自动接续**：次日的路线默认从前一天最后一个节点出发（可一键改为从本日第一地出发）
- **地点管理**：节点支持 类型标记（途经、景点、餐饮、加油充电、住宿）、停留时长、拖拽排序（vuedraggable）与上下移动按钮；单日节点上限 16 个
- **添加方式**：关键词搜索（防抖 400ms）、地图点选（逆地理编码自动命名）、当前位置定位
- **路线计算**：每天一次驾车路径规划请求；开源模式（OSRM）同时返回**每一段的真实里程与时长**，高德模式无分段数据时按直线近似；按「点序列+策略+数据源」哈希缓存，点没变不重复请求
- **地图展示**：每天一条彩色折线（含跨天接续段）+ 编号标记；总览显示全部天，单日聚焦自动适配视野
- **时间轴推算**：出发时间 + 各段驾驶时长（优先真实分段数据）+ 停留时长，推算每个点的到达 / 出发时刻；单日驾驶超过阈值（默认 8 小时，可调）醒目提醒
- **全程总览**：总里程 / 总驾驶时长；每日明细行可点击进入；总览默认只读，点「编辑」才显示行程设置与数据管理（导入 / 导出 / 删除）
- **路线策略**：速度最快 / 距离最短 / 少收费（切换后全程重算；开源模式下 OSRM 演示服务仅默认策略）
- **数据**：localStorage 自动保存（路书库，含路线折线缓存，超限时自动降级）；导出 / 导入 JSON（导入即新增一路书）
- **响应式**：PC 左面板 + 右地图；移动端地图收起，点「🗺 地图」按钮按需全屏查看

## 技术栈

- Vue 3 `<script setup>` + TypeScript + Vite
- Pinia 状态管理（路线折线不进响应式，按 hash 存模块级 `pathCache`，避免大数组的响应式开销）
- vuedraggable（SortableJS）拖拽排序
- 双地图数据源（`services/map.ts` 统一调度，接口一致，随时切换）：
  - 开源：Leaflet 1.9 + OpenStreetMap 瓦片 + OSRM 路线 + Nominatim 搜索
  - 高德：JS API 2.0（Driving / PlaceSearch / Geocoder / Geolocation 插件，按需加载）

## 关键设计说明

- **坐标系**：坐标随数据源而定——开源模式为 **WGS-84**（与 OSM/浏览器定位一致），高德模式为 **GCJ-02**。数据源写入路线缓存 hash，切换时自动清缓存重算，避免混用偏移。未来导入 GPX 时按当前数据源决定是否转换。
- **Key 安全**：开源模式无需任何 Key；高德模式的 Key 在前端使用（JS API 本身如此），通过域名白名单防护。M2 将把路径规划、POI 搜索等 **Web 服务调用移到后端代理**，Key 不再下发到浏览器。
- **配额控制**：搜索防抖、路线按天缓存（hash 命中直接复用）、拖拽结束后才重算；开源模式遵守 Nominatim 每秒 1 次的使用限制。
- **途经点上限**：高德与 OSRM 均按 16 个途经点测试上限，超出会提示拆分到其他天。

## 已知限制（按规划在 M2/M3 解决）

- 无后端：账号、云同步、分享链接未实现；多设备用「导出/导入 JSON」过渡
- 时间轴各段驾驶时长是按直线距离分摊的近似值（单日一次路线请求），M2 改为分段精确计算
- 开源模式下路线策略不生效（OSRM 演示服务限制）、过路费无数据；「沿途搜索」（沿折线采样做周边搜索）、导航跳转、天气等未实现
- Nominatim / OSRM 为公共演示服务，仅适合开发测试，生产环境需自建或换商用服务并注意用量限制
